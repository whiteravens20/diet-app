# Image credits

Food photography used in the Diet App UI (page banners + empty states), curated
via [Wikimedia Commons](https://commons.wikimedia.org) and committed here so the
app needs no runtime third-party image hosts. Each image is free to use under the
license noted; attribution is provided as required by CC BY (CC0 images need no
attribution, but are credited anyway).

Images were resized and re-encoded to WebP. None of the sources carry a
share-alike term, so these adaptations impose no additional license obligations.
