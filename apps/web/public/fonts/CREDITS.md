# Font credits

The typeface of the printed shopping list, committed here so that the app asks
no third-party font host for it.

| Files | Typeface | Authors | Source | License |
|---|---|---|---|---|
| `Inter-Regular.ttf`, `Inter-Bold.ttf` | Inter 4.1 | The Inter Project Authors | [rsms/inter, release v4.1](https://github.com/rsms/inter/releases/tag/v4.1), `extras/ttf` | [SIL Open Font License 1.1](OFL.txt) |

The files are the release's own, unchanged: every glyph of the typeface, so
that a list prints in one typeface whatever it names. The license asks that its
text and the copyright notice go wherever the files go; both are in `OFL.txt`
beside them.
